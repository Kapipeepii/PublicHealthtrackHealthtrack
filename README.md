# HealthTrack — คู่มือติดตั้งและใช้งาน

เว็บแอปบันทึกสุขภาพส่วนตัว (ผลแล็บ ยา นัดหมาย ออกกำลังกาย) ใช้บน iPhone ผ่านไอคอนหน้าจอโฮม สแกนข้อมูลจากรูปได้ และแจ้งเตือนเวลาทานยา/นัดหมายได้แม้ปิดแอป

- **ข้อมูลสุขภาพเก็บในเครื่องของคุณเอง** สิ่งเดียวที่ส่งไปเก็บบนเว็บของคุณ (Netlify ของคุณเอง) คือตารางเวลายา/นัด เพื่อให้ส่งแจ้งเตือนได้
- **ฟรีทั้งหมด** ใช้บัญชีของคุณเอง 3 อย่าง: GitHub, Netlify, Google (Gemini) ไม่ต้องเสียเงิน
- **ต้องมี:** iPhone ที่เป็น iOS 16.4 ขึ้นไป + Safari, อีเมล, เวลาประมาณ 30 นาที

> **ข้อควรทราบ** แอปนี้เป็นเครื่องมือจดบันทึกส่วนตัว **ไม่ใช่อุปกรณ์หรือคำแนะนำทางการแพทย์** การแจ้งเตือนอาจล่าช้าหรือไม่ถึงได้ (เช่น ปัญหาเครือข่าย ระบบ iOS หรือ Netlify) อย่าใช้เป็นช่องทางเดียวในการจำเวลาทานยา ผู้เผยแพร่โค้ดไม่รับผิดชอบต่อความเสียหายใดๆ จากการใช้งาน (ดู `LICENSE`)

**ติดตั้งได้จากมือถือล้วนๆ** ทุกขั้นในส่วนที่ 1 ทำบน iPhone ได้ (ดูกล่อง "ทำบนมือถือ" ด้านล่าง) มีเพียงการอัปเดตเวอร์ชันที่ต้องใช้คอมพิวเตอร์

## ส่วนที่ 1 ติดตั้ง (ทำครั้งเดียว)

### ขั้น 1 สมัคร GitHub
1. เปิด **https://github.com/signup** สมัครด้วยอีเมลของคุณ แล้วกดยืนยันอีเมล
2. ใช้แผน Free ได้เลย

### ขั้น 2 สร้างเว็บของคุณบน Netlify
1. กดปุ่มนี้:

   [![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/Kapipeepii/healthtrack-app)

2. เมื่อให้เข้าสู่ระบบ Netlify เลือก **Sign up with GitHub** (ถ้ายังไม่มีบัญชี Netlify ระบบจะสร้างให้ หรือสมัครเองที่ https://app.netlify.com/signup)
3. อนุญาตให้ Netlify เชื่อม GitHub แล้วกด **Save & Deploy** (ระบบจะคัดลอกโค้ดเข้า GitHub ของคุณ และสร้างเว็บให้เอง)
4. รอ 1-2 นาทีจนสถานะเป็น **Published** แล้วจดที่อยู่เว็บของคุณ (รูปแบบ `https://ชื่อ.netlify.app`)
5. (ไม่บังคับ แต่แนะนำ) **เปลี่ยนชื่อเว็บให้จำง่าย** ชื่อที่ Netlify สุ่มให้จะเป็นคำแปลกๆ เช่น `thunderous-kringle-9379ea`
   1. ในหน้าเว็บของคุณไปที่ **Project configuration** → **General** → **Project details** → **Change project name**
   2. พิมพ์ชื่อใหม่ (ตัวอักษรอังกฤษ ตัวเลข และ `-` ถ้าชื่อซ้ำกับคนอื่นจะใช้ไม่ได้) → **Save**
   3. ที่อยู่เว็บจะเปลี่ยนเป็น `https://ชื่อใหม่.netlify.app` (ชื่อเมนูอาจต่างจากนี้เล็กน้อยตามที่ Netlify ปรับหน้าจอ)
   4. **ควรเปลี่ยนก่อนทำขั้น 7** เพราะถ้าติดตั้งไอคอนลงหน้าจอโฮมและเปิด Push ไปแล้วค่อยเปลี่ยนชื่อ ไอคอนเดิมและข้อมูลในแอปจะผูกกับที่อยู่เก่า ต้องติดตั้งใหม่ ใช้ชื่อใหม่ในขั้น 3 เป็นต้นไป

> เว็บยังแจ้งเตือนไม่ได้จนกว่าจะทำขั้น 3-5 เสร็จ

### ขั้น 3 สร้างกุญแจ Push (3 ค่า)
1. เปิดลิงก์นี้ (เปลี่ยน `ชื่อ` เป็นชื่อเว็บของคุณ):
   `https://ชื่อ.netlify.app/.netlify/functions/vapid?setup=1`
2. พิมพ์**อีเมลจริงของคุณ**ในช่องแรก (ใช้เป็นช่องทางติดต่อของระบบ Push ไม่ได้ส่งอีเมลหาคุณ)
3. กดปุ่ม **คัดลอกทั้ง 3 ค่า** ระบบจะคัดลอกข้อความ 3 บรรทัด (`VAPID_PUBLIC_KEY=...`, `VAPID_PRIVATE_KEY=...`, `VAPID_SUBJECT=mailto:...`) ในครั้งเดียว
4. **ห้ามรีเฟรชหน้านี้ระหว่างทำขั้น 4** เพราะจะได้คีย์ชุดใหม่ ค่าทั้งหมดต้องมาจากการเปิดหน้าครั้งเดียวกัน
5. `VAPID_PRIVATE_KEY` เป็นความลับ ห้ามส่งหรือโพสต์ให้ใคร

### ขั้น 4 ใส่ค่าลงใน Netlify (วางครั้งเดียว)
1. เปิดแท็บใหม่ ไปที่ https://app.netlify.com → เลือกเว็บของคุณ → **Project configuration** → **Environment variables**
2. กด **Add a variable** → เลือก **Import from a .env file**
3. แตะช่องข้อความ แล้ว**วาง**ที่คัดลอกมาจากขั้น 3 (ต้องเห็น 3 บรรทัด)
4. ส่วนตัวเลือก scope/deploy context ปล่อยตามค่าเดิมที่ Netlify ตั้งไว้ให้ (ต้องครอบคลุมการใช้งานใน Functions) → กด **Import variables**
5. ตรวจว่าในรายการมีตัวแปรครบ 3 ตัว: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`

<details>
<summary>วิธีสำรอง ถ้าเมนู Import ไม่มีหรือวางไม่ได้ ให้เพิ่มทีละตัว</summary>

กด **Add a variable** แล้วเพิ่มทีละตัว (พิมพ์ชื่อให้ตรงทุกตัวอักษร ตัวพิมพ์ใหญ่) โดยใช้ปุ่ม "คัดลอกทีละค่า" ในหน้า `?setup=1`:

| ชื่อ (Key) | ค่า (Value) |
|---|---|
| `VAPID_PUBLIC_KEY` | ค่าจากหน้า `?setup=1` |
| `VAPID_PRIVATE_KEY` | ค่าจากหน้า `?setup=1` |
| `VAPID_SUBJECT` | `mailto:อีเมลจริงของคุณ` เช่น `mailto:somchai@gmail.com` |

ถ้ามีตัวเลือก "Contains secret values" ให้ติ๊กกับ `VAPID_PRIVATE_KEY`

</details>

### ขั้น 5 สั่ง Deploy ใหม่ 1 ครั้ง (สำคัญ)
Netlify ไม่ใช้ค่าที่เพิ่งใส่กับเว็บที่ Deploy ไปแล้ว ต้องสั่งใหม่:

1. ในหน้าเว็บของคุณ ไปที่ **Deploys** → **Trigger deploy** → **Deploy project** (หรือ **Deploy site** ตามชื่อที่ Netlify แสดง)
2. รอจนเป็น **Published**
3. ตรวจว่าสำเร็จ: เปิด `https://ชื่อ.netlify.app/.netlify/functions/vapid` ควรเห็นข้อความ `{"publicKey":"B..."}` (ถ้าเห็น `not_configured` แปลว่าชื่อตัวแปรผิด หรือยังไม่ได้ Deploy ใหม่)

### ขั้น 6 ขอ Gemini API key (ไว้สแกนรูป)
1. เปิด **https://aistudio.google.com/app/apikey** ล็อกอินด้วยบัญชี Google
2. กด **Create API key** แล้วคัดลอกคีย์ (ขึ้นต้นด้วย `AIza`) เก็บไว้ใน Notes
3. ฟรีแต่มีโควตาจำกัดต่อวัน/นาที

### ขั้น 7 ติดตั้งลง iPhone
1. เปิดเว็บของคุณใน **Safari** (ต้องเป็น Safari)
2. กดปุ่มแชร์ → **Add to Home Screen** (เพิ่มลงหน้าจอโฮม)
3. ตั้งชื่อไอคอนตามต้องการ แล้วกด **Add**
4. **เปิดแอปจากไอคอนบนหน้าจอโฮมเท่านั้น** (ไม่ใช่จาก Safari) การแจ้งเตือนจึงจะทำงาน
5. ข้อมูลที่กรอกใน Safari กับในแอปจากไอคอนเก็บแยกกัน ให้กรอกข้อมูลจริงในแอปจากไอคอนเท่านั้น

### ขั้น 8 ตั้งค่าในแอป (แท็บ ⚙️ ข้อมูล)
1. **ชื่อแอป** พิมพ์ชื่อที่ชอบ → บันทึกชื่อ
2. **Gemini** วางคีย์จากขั้น 6 → บันทึกคีย์
3. **แจ้งเตือน ขั้นที่ 1** กดทดสอบแจ้งเตือน แล้วเลือก อนุญาต
4. **แจ้งเตือน ขั้นที่ 2** กด **เปิดใช้งาน Push แจ้งเตือน** แล้วเลือก อนุญาต

เสร็จแล้ว ลองเพิ่มยาที่เวลาอีก 1-2 ชั่วโมงข้างหน้า แล้วปิดแอปและล็อกจอ ถ้าแจ้งเตือนเด้ง แปลว่าติดตั้งครบ

### ทำบนมือถือ (iPhone)
- ใช้ **Safari** ทุกขั้น (ไม่ใช่เบราว์เซอร์ในแอป Line/Facebook) และอย่าเปิดหลายหน้า Netlify ซ้อนกัน
- เปิดแท็บ Safari 2 แท็บสลับกันได้ แตะปุ่มแท็บมุมล่างขวา → เครื่องหมาย + แท็บหนึ่งไว้หน้า `?setup=1` อีกแท็บไว้หน้า Environment variables ของ Netlify
- ถ้าหน้า Netlify บนมือถือไม่แสดงเมนูหรือปุ่มครบ ให้แตะ **ᴀA** ในแถบที่อยู่ของ Safari → **Request Desktop Website** แล้วโหลดหน้าใหม่
- ชื่อเมนูใน Netlify อาจเปลี่ยนตามที่ Netlify ปรับหน้าจอ ถ้าไม่เจอชื่อที่ระบุ ให้มองหาเมนูที่ใกล้เคียง (Project configuration / Site configuration, Environment variables)
- ขั้น **อัปเดตเวอร์ชัน** (ส่วนที่ 3) ต้องใช้คอมพิวเตอร์ ถ้าไม่มี ไม่ต้องอัปเดต แอปเวอร์ชันเดิมใช้งานต่อได้ตามปกติ

## ส่วนที่ 2 วิธีใช้งาน

| แท็บ | ใช้ทำอะไร |
|---|---|
| 🏠 หน้าแรก | สรุปสถานะ ยาที่ต้องกินวันนี้ (ติ๊ก "กินแล้ว" แล้วจะหายไปจากหน้านี้) นัดที่ใกล้ถึง |
| 🧪 ผลแล็บ | บันทึกผลตรวจ ดูกราฟแนวโน้ม สแกนจากรูปผลตรวจด้วย Gemini |
| 💊 ยา | เพิ่มยา ตั้งเวลาทานได้ตามใจ (เช้า/กลางวัน/เย็น/ก่อนนอน หรือกำหนดเวลาเอง) สแกนจากฉลากยาได้ |
| 📅 นัดหมาย | บันทึกนัดแพทย์ ระบบเตือนล่วงหน้า 3 วันและ 1 วัน |
| 🏃 ออกกำลังกาย | บันทึกการออกกำลังกาย |
| ⚙️ ข้อมูล | ชื่อแอป, Gemini key, สำรอง/นำเข้าข้อมูล, ตั้งค่าแจ้งเตือน, เวอร์ชัน |

**เรื่องควรรู้**
- **สำรองข้อมูลเป็นประจำ** ข้อมูลอยู่ในเครื่องเท่านั้น ถ้าลบแอป ล้างข้อมูล Safari หรือเปลี่ยนเครื่อง ข้อมูลจะหาย ไปที่แท็บ ข้อมูล → **Export JSON** แล้วเก็บไฟล์ไว้ (ย้ายเครื่องใช้ **Import JSON**) ไฟล์ Export ไม่มี Gemini key
- **การแจ้งเตือน Push อาจช้ากว่าเวลาที่ตั้ง 1-2 ชั่วโมง** เพราะเซิร์ฟเวอร์เช็กทุกชั่วโมง
- ถ้าติ๊ก "กินแล้ว" ก่อนถึงเวลา Push จะข้ามมื้อนั้น
- เวลาแจ้งเตือนคิดตามเวลาประเทศไทย (UTC+7)
- แอปนี้เป็นเครื่องมือจดบันทึก ไม่ใช่คำแนะนำทางการแพทย์ สงสัยเรื่องยา/ผลตรวจให้ถามแพทย์หรือเภสัชกร

## ส่วนที่ 3 ดูแลรักษา

### เครดิตฟรีของ Netlify
- แผน Free ได้ **300 เครดิต/เดือน** และเป็นเพดานแข็ง ถ้าใช้หมด เว็บอาจหยุดทำงานชั่วคราวจนถึงรอบเดือนถัดไป
- **การ Deploy แต่ละครั้งใช้ประมาณ 15 เครดิต** (ตามข้อมูลที่ Netlify เผยแพร่ ณ ตุลาคม 2026 อัตราอาจเปลี่ยนได้ ตรวจที่ https://www.netlify.com/pricing) ดังนั้นอย่าสั่ง Deploy หรือแก้ไฟล์ใน GitHub บ่อย เพราะทุกครั้งที่แก้ไฟล์ใน repo เว็บจะ Deploy ให้เองและเสียเครดิต
- การติดตั้งครั้งแรกตามคู่มือนี้ใช้ Deploy 2 ครั้ง (ประมาณ 30 เครดิต)
- เครดิตยังถูกหักจากการใช้งานฟังก์ชัน (ตัวเช็กแจ้งเตือนรายชั่วโมง) ปริมาณข้อมูล และจำนวนคำขอเข้าเว็บด้วย แต่การใช้ส่วนตัว 1-2 เครื่องโดยทั่วไปใช้น้อยกว่าการ Deploy มาก รายละเอียดดูที่ https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/how-credits-work/
- ดูเครดิตที่ใช้ไป: เข้า https://app.netlify.com → หน้าตั้งค่าของ Team → **Billing / Usage** (ชื่อเมนูอาจต่างกันเล็กน้อยตามที่ Netlify ปรับ) ควรเช็กเดือนละครั้ง

### อัปเดตเป็นเวอร์ชันใหม่ (ทำเมื่อผู้ดูแลแจ้งเท่านั้น)
1. รับไฟล์ zip เวอร์ชันใหม่ แล้ว **แตกไฟล์** บนคอมพิวเตอร์ (ห้ามอัปโหลดตัว zip)
2. เปิด repo ของคุณบน GitHub → **Add file** → **Upload files** → ลากไฟล์และโฟลเดอร์ที่แตกแล้วมาวาง → **Commit changes**
   - หลังอัปโหลด ตรวจว่า repo ยังมีโฟลเดอร์ `netlify`, `public` และ `scripts` ครบ (ถ้าโฟลเดอร์ใดหายไป ให้อัปโหลดโฟลเดอร์นั้นอีกครั้ง)
3. Netlify จะ Deploy ให้เอง รอจนเป็น Published
4. เปิดแอปจากไอคอน → แท็บ ข้อมูล → ดูเลขเวอร์ชันด้านล่าง (ถ้ายังเป็นเลขเดิม ปิดแอปแบบปัดทิ้งแล้วเปิดใหม่ 1-2 ครั้ง)

### คีย์ Push
อย่าลบหรือสร้างคีย์ใหม่โดยไม่จำเป็น ถ้าเปลี่ยนคีย์ ต้องกด **เปิดใช้งาน Push** ใหม่ในทุกเครื่อง

| อาการ | ลองทำ |
